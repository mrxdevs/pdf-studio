How to edit text in a PDF (free, no upload)

You can change the text in a PDF, like a wrong date, a name or an amount, without Adobe Acrobat and without uploading the file anywhere. PDF Studio does it in your browser in about a minute.

Open PDF Studio, freeNo sign-up. Your file never leaves your device.

Edit existing text in 5 steps

  1. Open your PDF. Go to pdfstudio.mrxamjad.com and tap Open PDF, or drag the file onto the page. On a phone it opens from Files, Downloads or Google Drive like any other file picker.
  2. Choose the Edit text tool. It is the second tool after Text in the toolbar (on a phone, the bar along the bottom of the screen).
  3. Tap the line you want to change. PDF Studio finds that line in the PDF, covers it with the background color picked up from the page, and puts a text box in its place with the same words, a matching color and a close size.
  4. Type the new text. Fix the typo, change the date or the amount, or rewrite the whole line. Use the style panel to change font, size, color, bold, italic, underline or alignment.
  5. Download or print. Tap Download to save a new file named yourfile-edited.pdf, or Print. The new words are real, selectable PDF text, not a picture.

Adding new text instead

To add words where there were none (filling in a form that has no fields, writing a note, labelling a diagram), pick the Text tool and tap anywhere on the page. You get a text box you can move, resize, restyle and delete. There are seven fonts: Helvetica, Times and Courier for documents, Poppins and Lato for a modern look, Great Vibes for a handwritten signature and Pacifico for something playful. Any color works, and you can give a text box its own background color.

What "editing text in a PDF" really means

A PDF is not a word-processor file. Each line is placed at an exact position with an exact font, and there is no paragraph that reflows when you change a word. That is why most PDF editors, including the expensive ones, edit text the same way underneath: they remove or cover the old glyphs and draw new ones in the same place.

PDF Studio does this openly. The original line is covered with a solid box in the page's background color, and the new text is drawn on top in the closest standard font. On plain white or single-color backgrounds the result is hard to tell apart from the original. Two honest limits:

  • Fonts: the replacement uses the nearest of the seven built-in fonts, not the exact font embedded in your PDF. Most invoices, letters and forms use Helvetica, Arial or Times, which match closely.
  • Scripts: English and other Latin-script text works, and so does the ₹ sign. Hindi, Tamil and other Indian scripts are not supported yet. That is an open issue anyone can help with.

Tips for a clean edit

  • Zoom in before you tap a line, so you hit the right one.
  • If the new text is longer than the old, drag the box wider or reduce the size a step.
  • On a patterned or photo background, use the Whiteout tool with a matching fill color, then add text on top.
  • Made a mistake? Undo and Redo are in the top bar (Ctrl+Z and Ctrl+Shift+Z on a laptop).

Frequently asked questions

Can I edit text in a PDF for free?

Yes. PDF Studio is free with no sign-up, no watermark and no page limit. It is open source under the MIT license.

Do I need to upload my PDF?

No. The PDF is opened, edited and saved inside your browser. It is never sent to a server, so it is safe for invoices, ID documents and contracts.

Will the edited text match the original font?

Closely, not exactly. PDF Studio picks the nearest of its built-in fonts (Helvetica, Times, Courier and others) and matches the color and size. Exact in-place font matching is on the roadmap.

Can I edit a scanned PDF?

A scanned page is a picture, so there is no text to tap. You can still cover any area with Whiteout and type new text on top of it.

Does it work on a phone?

Yes. PDF Studio works in Chrome and Safari on Android and iPhone, with touch to move and resize text, and a Share button on phones that support it.
