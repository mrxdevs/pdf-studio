About PDF Studio

PDF Studio is a free, open-source PDF editor that runs entirely in your web browser. It was built by Amjad Ali, a mobile and web developer in Chennai, India, and launched in November 2026.

What PDF Studio does

  • Add text anywhere, in 7 fonts (Helvetica, Times, Courier, Poppins, Lato, Great Vibes, Pacifico), any size and color, with bold, italic, underline, alignment and a background color.
  • Edit existing text: tap a line in the PDF to cover it with the page's background color and retype it in a matching color and size.
  • Insert images (PNG, JPG and other browser-readable formats): move, resize, set opacity.
  • Sign: draw a signature by hand, type one in a script font, or insert a signature image.
  • Mark up: whiteout, highlight, rectangles with borders, freehand drawing.
  • Pages: rotate, delete, reorder, add blank pages; thumbnails and zoom.
  • Output: download a real PDF, with vector text and embedded fonts and images, or print it. On phones that support it, share the file directly.
  • Undo and redo, keyboard shortcuts on desktop, touch-friendly controls on phones, and password-protected PDFs.

Who it's for

Anyone who needs a quick PDF fix without installing software, buying a subscription or uploading a private document: correcting an invoice, filling in a form that has no fields, signing an agreement on a phone, adding a logo to a quotation, or removing a page.

Known limitations

  • Edited text uses the closest built-in font, not the exact font embedded in the original PDF.
  • Indian scripts such as Devanagari (Hindi) and Tamil are not supported for typing yet.
  • Scanned PDFs are images: text in them can be covered and retyped, but not detected.
  • No offline or installable app yet, and bookmarks may not survive page reordering.

All of these are open issues on GitHub, and contributions are welcome.
